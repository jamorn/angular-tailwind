## งานที่ได้แก้ไขวันนี้ (HTML & CSS)

### 1. ปรับรูปแบบปุ่ม Navigation (Sticky Group Button)
- ปรับให้ปุ่ม navigation ของหน้า **Giveaway** และ **OEE** ใช้คลาสเดียวกัน:
  ```
  sticky top-16 z-30 flex flex-wrap gap-2 justify-center p-4 bg-white/60 border border-blue-400 rounded-lg shadow-md
  ```
- ทำให้ปุ่ม navigation ดูโดดเด่นและมีความสอดคล้องกันทั้งสองหน้า

### 2. ปรับ Layout และ Style ของกราฟ
- กราฟแต่ละเครื่องจักรใช้พื้นหลัง `bg-card` ขอบขาว `border border-white` และเงา `shadow-lg`
- ใช้ `space-y-4` เพื่อเว้นระยะห่างระหว่างกราฟแต่ละตัว

### 3. ปรับปรุง Theme และ Responsive
- ปรับพื้นหลังและสีของหัวข้อให้เหมาะสม (`bg-slate-800 text-white`)
- ปรับความโปร่งใสของปุ่ม navigation (`bg-white/60`)
- ปรับขอบและความโค้งมน (`border-blue-400 rounded-lg`)

### 4. แก้ไข TypeScript
- เพิ่ม type สำหรับปุ่ม (`type ButtonToneType = ...`)
- เพิ่ม property `currentTheme` และ subscribe theme ใน OEE ให้เหมือนกับ Giveaway
- Import `ButtonComponent` ในทั้งสองหน้า
